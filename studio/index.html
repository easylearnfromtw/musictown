登入 CITYMUS Studio

使用 Email 驗證連結登入；首次登入可自動建立帳號。

驗證信打開後跑到 localhost:3000？在這裡完成登入

從 Gmail 或其他 Email App 長按信中的「登入」按鈕 → 複製連結，不要先點開。新版也能辨識 Gmail、Google、Outlook 常見的轉址包裝。網址只在本頁解析並交由 Supabase 驗證，不會交給 CITYMUS 伺服器儲存。

若你貼的是 Gmail「信件頁面」或已經開過的舊連結，就無法登入。請重新寄送一封信，再長按信件內的登入按鈕複製連結。正式的一鍵登入仍需 Supabase 管理員修正 Site URL 與 Redirect URLs。

我的播放清單

選取一份播放清單編輯，或新增一份供網站嵌入。

我的網站授權

登入後將網站與指定播放清單綁定。共用 API Key 不提供管理權限，每個網站可獨立撤銷授權。

建立播放清單

音檔必須是公開 HTTPS 直連 mp3、m4a、ogg 等格式，且須由你持有使用權或取得授權；不支援直接輸入 YouTube／Spotify 網址。每份最多 40 首。

綁定網站授權

所有網站使用相同的公開 API Key；每位會員最多 10 個網站授權。

每行填入一個完整的 HTTPS 網站來源（不含路徑）。網站綁定限制瀏覽器嵌入，不能代替私密驗證；公開音樂資料可被直接讀取。

必要來源聲明：使用 CITYMUS 播放器或 API 的網站，必須在播放器旁或明顯位置標示「Powered by CITYMUS」並連結至 CITYMUS 官方網站；不得移除或遮蔽播放器中的標示，音源仍須遵守原有授權。
